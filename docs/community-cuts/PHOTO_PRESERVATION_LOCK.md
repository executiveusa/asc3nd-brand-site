1. the owner explicitly approves the destructive change;
2. the source Drive masters are verified accessible;
3. the replacement set is count-verified;
4. the import audit is updated;
5. the event gallery still resolves every approved media item;
6. rollback to commit `3582788f7adf6a67c782be104dd90f5e9904dc9c` remains possible.

Homepage curation must never be implemented by deleting archive photos.

The homepage may show a small subset. The event record and archive preserve the full approved set.
