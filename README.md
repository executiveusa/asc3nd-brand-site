# ASC3ND Brand Site

Canonical public-brand repository for ASC3ND.

## Governing idea

## Architecture

- Next.js App Router
- TypeScript
- No generic component library
- Editorial layout system
- Documentary media slots
- Mobile recomposition, not desktop shrinking
- Reduced-motion support

## Protected boundary
