# ASC3ND Design System

## Governing idea

**Community came through. Now we build forward.**

The interface should feel authored, civic, documentary, restrained, and contemporary. The system exists to reduce decisions while preserving brand specificity.

## Design law

Nothing remains unless it improves understanding, trust, or action.

## Reusable system

Reuse:
- layout shell and responsive grid
- typographic scale logic
- documentary media primitive
- section rhythm
- focus and reduced-motion behavior
- content contracts
- participation-row interaction pattern

Do not blindly reuse:
- governing idea
- copy
- image world
- brand colors
- exact composition
- signature interaction
- cultural references

## Current tokens

- Paper: `#F5F2E8`
- Ink: `#120F0B`
- Field: `#071513`
- Marker: `#E8B85F`
- Maximum shell: `1460px`

Typography uses a restrained editorial serif / neutral sans pairing until final licensed brand typography is approved.

## Documentary media slots

1. Cinematic landscape
2. Portrait interview
3. Documentary still
4. Evidence moment
5. Field note

Every real media asset must carry, as applicable: crop, poster, caption, transcript, credit, consent, and mobile treatment.

## Homepage narrative

1. Thesis
2. First evidence
3. Community Roll
4. Founder belief
5. Developing pathways
6. Participation routes

No unverified metrics, fabricated outcomes, stock youth imagery, generated people, decorative gradients, generic card grids, or motion without a user purpose.

## Mobile rule

Mobile is recomposed, not merely scaled. Maintain readable type, 44px+ practical touch targets, no horizontal overflow, and preserve documentary pacing.
