# ASC3ND Agent Instructions

## Source of truth
This repository is the canonical codebase for the new ASC3ND public brand site.

## Design doctrine
- Strategy before styling.
- Content before containers.
- Proof before claims.
- Systems before isolated screens.
- Minimum necessary interface around maximum useful capability.
- Every element must earn its place.
- Mobile is intentionally recomposed.
- Motion must communicate hierarchy, orientation, feedback, pacing, or brand expression.

## Protected boundary
Do not alter, recreate, or silently replace RSVP, confirmation, staff auth, check-in, export, or database behavior from the legacy event system.

## Build rules
1. Inspect before changing.
2. Work in bounded slices.
3. Preserve working behavior.
4. Do not fabricate content or metrics.
5. No generic component library unless justified.
6. No stock/generated youth imagery in place of documentary evidence.
7. Keep all consequential deployment claims tied to exact SHA evidence.
8. Builder cannot approve its own release.

## Release gate
No production cutover until build, mobile, accessibility, content, runtime, ownership, rollback, and independent Gauntlet checks pass.
