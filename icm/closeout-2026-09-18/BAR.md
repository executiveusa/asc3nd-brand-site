# Bar

## DESIGN BAR
COLLINS-level structural craft:
- authored hierarchy;
- restraint;
- deliberate typography and spacing;
- proof integrated into story;
- mobile designed intentionally;
- accessibility verified manually;
- no template/AI slop.

This is a quality bar, not a request to visually imitate COLLINS.

## NONPROFIT / FUNDING BAR
A skeptical foundation officer, sponsor, journalist, parent, partner, board candidate, or donor should be able to investigate ASC3ND and gain confidence rather than accumulate avoidable questions.

Minimum funding/trust gates:
- exact public/legal identity resolved or transparently unknown;
- no tax-deductibility overclaim;
- one active program stated truthfully;
- one evidence-backed public case study;
- youth/privacy boundaries published;
- operational safeguarding path documented or explicitly pending owner approval;
- partner/participant/outcome claims verified before publication;
- public forms tested end-to-end;
- one canonical domain/site;
- crawlable SEO/search basics;
- ownership and handoff documented.

## RELEASE BAR
Do not call a release complete from code, CI, or deployment alone.

Required:
- exact revision identified;
- production runtime checked;
- 0 public construction placeholders;
- 0 broken core controls;
- 0 known mobile horizontal overflow;
- keyboard journey checked;
- forms checked;
- rollback documented;
- owner approval for consequential production cutover.

## HANDOFF BAR
Another competent operator should be able to:
- locate the canonical repositories;
- update the site;
- find organizational proof;
- understand which facts are verified vs unknown;
- respond to intake;
- recover accounts;
- review grant opportunities;
- roll back a release;
without interviewing the original builder.

## COMMERCIAL BAR
The engagement should leave both:
1. a finished ASC3ND system;
2. a reusable, demonstrable nonprofit/social-purpose offer derived from verified ASC3ND learning.
